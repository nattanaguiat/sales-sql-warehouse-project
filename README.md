
# 📊 Sales Data Warehouse & Analytics Project

Welcome to the **Sales Data Warehouse & Analytics Project** repository! 🚀

This project aims to develop an end-to-end data warehousing and analytics solution, from integrating raw sales data to generating actionable business insights.

Designed as a portfolio project, it demonstrates practical skills and industry best practices in **Data Engineering, ETL Development, Data Modeling, SQL, and Business Intelligence**.

---

## 🚀 Project Requirements

### Building the Data Warehouse (Data Engineering)

#### Objective

Develop a modern data warehouse using **PostgreSQL, Docker, and Python** to consolidate customer, product, and sales data from multiple CSV files, enabling analytical reporting and informed business decision-making.

#### Specifications

- **Data Sources:** Import data from two source systems (ERP and CRM) provided as CSV Files.
- **Data Quality:** Cleanse and resolve data quality issues prior to analysis.
- **Data Integration:** Combine customer, product, and sales information into a unified data model optimized for analytical queries.
- **Scope:** Work with the most recent dataset, without maintaining historical versions of the data.
- **Documentation:** Provide clear documentation of the database model to support both business and stakeholders and analytics teams.

---

### Data Architecture

The project follows the **Medallion Architecture**, organizing data into three layers:

- **Bronze Layer:** Stores raw data extracted from the original CSV files.
- **Silver Layer:** Contains cleaned, standardized, and integrated datasets.
- **Gold Layer:** Provides business-ready fact and dimension tables optimized for analytics and reporting.

## 🎯 Project Goals

- Build an end-to-end ETL pipeline using Python and SQL.
- Integrate multiple CSV datasets into PostgreSQL.
